## Problema

ChromaDB 0.6.3 crasheaba con:
```
PermissionError: [Errno 13] Permission denied: '/chroma/chroma.log'
ValueError: Unable to configure handler 'file'
```

Causa raiz: el manifiesto referenciaba un ConfigMap `chroma-log-config` que **nunca se creo**.
Sin el ConfigMap, ChromaDB cargaba su `log_config.yml` por defecto que incluye un handler `file`
que escribe en `/chroma/chroma.log`. Como el contenedor corre con UID 1000 y `/chroma` es de root,
el proceso muere al intentar abrir el fichero.

Gemini intento: runAsUser 0, montar PVC en /chroma (enmascaro codigo), subPath sin ConfigMap real.
Ninguna solucion funciono porque ninguna atacaba la causa raiz.

## Lo que se hizo

### Fix ChromaDB
- Diagnosticado que el ConfigMap `chroma-log-config` no existia (confirmado con grep en repo)
- Creado el ConfigMap en `k8s/chromadb.yaml` con `log_config.yml` que:
  - Solo usa handler `console` (stdout)
  - Elimina handler `file` (el que causaba el PermissionError)
- Jay copio el contenido del archivo al PC de empresa (copy-paste, sin git — entornos separados)
- `kubectl apply -f k8s/chromadb.yaml` + `kubectl delete pod chromadb-0` → **ChromaDB Running**
