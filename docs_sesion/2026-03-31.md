## Lo que se hizo

### Bloque 2 — Core (`agent/remediation.py`)
Modulo nuevo (~170 lineas), 0 dependencias externas:
- `CommandSafety` enum: SAFE (read-only), MUTATING (permitido), BLOCKED (destructivo), UNKNOWN
- Patrones regex: BLOCKED_PATTERNS (drain, delete ns/pvc, rm -rf, force-delete, cordon, taint),
  SAFE_PATTERNS (describe, get, logs, top, events, version),
  MUTATING_PATTERNS (set resources, rollout restart, scale, patch, label, annotate)
- `classify_command()` — evalua BLOCKED primero (maxima prioridad)
- `validate_commands()` — clasifica lista de comandos
- `decide_action()` — 7 reglas en cascada (disabled -> suggest, blocked -> escalate, etc.)
- `execute_commands()` — stub DRY-RUN (S5 reemplaza con ejecucion real)
- `process_remediation()` — entry point: validate -> decide -> execute -> resultado

### Bloque 3 — Tests (`tests/helpers.py` + `tests/test_remediation.py`)
- 2 nuevos mock factories en `helpers.py`:
  - `mock_diagnosis_auto_remediate()` — risk=low, confidence=0.9, comandos safe+mutating
  - `mock_diagnosis_escalate()` — risk=high, incluye `kubectl drain` (BLOCKED)
- 47 tests nuevos en `test_remediation.py`:
  - `TestClassifyCommand` (~25): SAFE, MUTATING, BLOCKED, edge cases
  - `TestValidateCommands` (~5): mixto, vacio, todos seguros
  - `TestDecideAction` (~9): todas las reglas del decision engine
  - `TestExecuteCommands` (~3): dry-run, multiples, vacio
  - `TestProcessRemediation` (~4): pipeline completo auto/escalate/disabled/sin comandos
- **47/47 tests nuevos pasando** (0.04s)
