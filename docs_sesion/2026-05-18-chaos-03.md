# Sesión Chaos Engineering #3 — 2026-05-18

**Mini-Fase 4 · Sesión #3** — Dashboard Grafana "AIOps — Chaos"

## Objetivo

Añadir un dashboard Grafana dedicado para visualizar las métricas chaos
(`aiops_chaos_*`) ya instrumentadas en sesiones #1 y #2. La sesión es scoped a
`k8s/grafana.yaml` + docs. Ejecución en cluster (screenshot) queda para la
siguiente ventana de Cloud Shell que también ejecute los experimentos pendientes.

## Decisiones tomadas

| Decisión | Elección | Motivo |
|---|---|---|
| Dashboard separado vs paneles en Overview | Dashboard nuevo "AIOps — Chaos" | Overview ya tiene 13 paneles; capturas dedicadas más legibles para defensa |
| Implementación K8s | Key `chaos.json` adicional en ConfigMap `grafana-dashboard-aiops` | Más simple que ConfigMap nuevo + subPath; el provider ya escanea `/var/lib/grafana/dashboards` |
| Paneles incluidos | MTTD/MTTR p95 + pie outcome + stat total + ALERTS correlation + tabla histórico | Cubre 4 ángulos: latencia, distribución, correlación con alertas, histórico |
| Ablation con/sin RAG | Pospuesto | Requiere flag runtime `RAG_ENABLED` + refactor pipeline; scope creep sesión #3 |
| Screenshot | PNG committeado en `docs/img/grafana-chaos.png` | Reproducible en repo |
