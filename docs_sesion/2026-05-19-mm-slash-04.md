# Sesión #4 — Slash command Mattermost `/aiops`

**Fecha:** 2026-05-19
**Mini-Fase 4 sesión:** 4/6
**Objetivo:** Añadir endpoint `POST /webhook/command` para slash commands MM.

## Scope

- Subcomandos: `/aiops status`, `/aiops incidents [N]`, `/aiops help`
- Auth: `MM_COMMAND_TOKEN` static shared secret (fail-open + warning startup)
- Response siempre `{"response_type": "ephemeral", ...}` — solo visible al invocador
- ~10 tests nuevos en `TestSlashCommandEndpoint`
quec
## Decisiones clave

| Decisión | Elegida | Descartada | Por qué |
|---|---|---|---|
| Pagination incidents | Default 5, configurable 1–20 | Sin argumento / sin tope | Flexibilidad para debugging, capped para no saturar MM |
| Order incidents | Por recencia (`metadata.timestamp` desc) | Por similitud semántica | Es ChatOps pull, no RAG retrieval |
| Form vs JSON | `Form()` FastAPI | JSON body | MM envía `application/x-www-form-urlencoded` nativo |
| Schema en schemas.py | Sí, `MattermostCommandPayload` | Form directo sin schema | Convención del repo — todos los payloads en schemas.py |
| Token auth | Static `hmac.compare_digest` | HMAC firmado | MM slash commands solo ofrecen shared secret, endpoint es read-only |
